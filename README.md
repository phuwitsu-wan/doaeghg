# บันทึกการปล่อยก๊าซเรือนกระจกภาคการเกษตร

จัดทำโดย กลุ่มอารักขาพืช สำนักงานเกษตรจังหวัดเพชรบูรณ์

เครื่องมือสำหรับเจ้าหน้าที่ส่งเสริมการเกษตร ใช้บันทึกข้อมูลกิจกรรมรายแปลง/รายฤดูกาล และคำนวณการปล่อยก๊าซเรือนกระจกตาม

- คู่มือ MRV การปล่อยก๊าซเรือนกระจกในภาคเกษตร (GIZ / TGC EMC, 2568), สมการ Eq.1–10
- 2006 IPCC Guidelines และ 2019 Refinement (Tier 1), GWP ตาม IPCC AR5
- ระเบียบวิธี T-VER ของ อบก.: P-METH-13-08 (ข้าว), S-METH-13-05 (พืชไร่/พืชผัก), S-METH-13-06 (ไม้ผล/พืชยืนต้น), P-METH-13-06 (Premium พืชไร่/ผัก/ไม้ผล), P-METH-14-03 (ถ่านชีวภาพ) และเครื่องมือ S-TOOL-01-01 (ต้นไม้), 01-02 (คาร์บอนในดิน), 01-03 (ไม้ตาย/เศษซาก)
- ทวนสอบกับตัวอย่าง “04_BE and PE calculation” (ดร.นิตยา/อบก.): N₂O จากปุ๋ย FSN 8.35/FON 2.7, ต้นตะแบก D 50 ซม. H 30 ม., เชื้อเพลิง CO₂ เท่านั้น (tests/tver.test.ts)
- ตารางพารามิเตอร์ (ต้องติดตามผล/ค่าคงที่) บนหน้าผลลัพธ์ และชีต “T-VER” ใน Excel สำหรับกรอก PDD/รายงานติดตามผล

## ความสามารถ

- พืช 5 กลุ่ม ได้แก่ ข้าว พืชไร่ พืชผัก ไม้ผล/พืชยืนต้น และป่าไม้
- เปรียบเทียบกรณีฐาน (BE) กับกรณีดำเนินโครงการ (PE) และประมาณการเครดิต T-VER พร้อมตรวจเงื่อนไขหลัก
- แบบบันทึกทีละขั้นตามลำดับฤดูกาล เลือกคำตอบด้วยการแตะ กรอกปุ๋ยเป็นกิโลกรัมหรือกระสอบได้ สอดคล้องกับแบบสำรวจ TGC EMC
- เป็น PWA ติดตั้งลงมือถือได้ ใช้ออฟไลน์ได้ และข้อมูลเก็บในเครื่อง
- ส่งออก Excel (รายแปลง/ทุกแปลง), พิมพ์เป็น PDF, สำรองและนำเข้าข้อมูลด้วยไฟล์ JSON
- หน้า “วิธีคำนวณ” แสดงสมการและค่าสัมประสิทธิ์ทุกตัวพร้อมแหล่งอ้างอิง

## เก็บข้อมูลผู้ใช้งานลง Google Sheets อัตโนมัติ

แอปส่งข้อมูลเข้า Google Sheets ของหน่วยงานเองทุกครั้งที่มีการใช้งาน ผู้ใช้ไม่ต้องตั้งค่าอะไร ถ้าเครื่องออฟไลน์จะเก็บไว้ส่งเมื่อกลับมาออนไลน์ และไม่ส่งชื่อเกษตรกร

**ข้อมูลที่ได้ใน Google Sheets (3 ชีต)**

| ชีต | 1 แถว = | คอลัมน์ |
|---|---|---|
| ผู้ใช้งาน | ผู้ใช้ 1 คน (อัปเดตแถวเดิม) | รหัส ชื่อ ตำแหน่ง หน่วยงาน จังหวัด โทรศัพท์ อีเมล วันลงทะเบียน วันยินยอม ใช้งานล่าสุด จำนวนครั้งที่เปิด/สร้างแปลง/ดาวน์โหลด |
| การใช้งาน | 1 กิจกรรม | เวลา กิจกรรม ผู้ใช้ หน่วยงาน จังหวัด รายละเอียด |
| ผลการคำนวณ | แปลง 1 แปลง (อัปเดตแถวเดิม) | ผู้บันทึก พืช มาตรฐาน จังหวัด อำเภอ ตำบล พื้นที่ ค่าการปล่อย kgCO2e/กก. ระดับ ปริมาณที่ลดได้ |

**ขั้นตอนติดตั้ง (ทำครั้งเดียว ประมาณ 5 นาที)**

1. สร้าง Google Sheets ใหม่ด้วยบัญชี Google ของหน่วยงาน ตั้งชื่อตามต้องการ
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจากไฟล์ `google-apps-script/Code.gs` กดบันทึก
3. เลือกฟังก์ชัน `setup` ที่แถบด้านบน แล้วกด **เรียกใช้** → อนุญาตสิทธิ์ (ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" กด ขั้นสูง → ไปที่โปรเจกต์) จะได้ 3 ชีตพร้อมหัวตาราง
4. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** → รูปเฟือง เลือก **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด ทำให้ใช้งานได้ แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
5. ทดสอบ: วาง URL ในเบราว์เซอร์ ต้องขึ้นข้อความ "ระบบรับข้อมูลทำงานปกติ"
6. ใส่ URL ในแอป เลือกวิธีใดวิธีหนึ่ง:
   - **ในโค้ด (bolt.new):** เปิด `src/config.ts` แล้ววาง URL ในบรรทัด `const COLLECT_URL = "…";` บันทึก แล้ว push ขึ้น GitHub ให้ Vercel deploy ใหม่
   - **บน Vercel (ไม่ต้องแก้โค้ด):** Project → Settings → Environment Variables → เพิ่ม `VITE_COLLECT_URL` = URL นั้น → Deployments → Redeploy
7. ตรวจสอบ: เปิดแอป ลงทะเบียน แล้วดูใน Google Sheets ชีต "ผู้ใช้งาน" ต้องมีชื่อขึ้นภายในไม่กี่วินาที หน้า "ตั้งค่า" ของแอปจะบอกสถานะการส่ง

ถ้าแก้โค้ด Apps Script ภายหลัง: **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (รูปดินสอ) → เวอร์ชัน: เวอร์ชันใหม่** URL จะยังเป็นอันเดิม

ผู้ใช้ทุกคนยังดาวน์โหลดประวัติการใช้งานของตัวเองเป็น Excel ได้ที่หน้า "ตั้งค่า"

## เทคโนโลยี

Vite 6 + React 19 + TypeScript + CSS ธรรมดา ไม่มี native binary และไม่มีไลบรารี Excel ภายนอก (สร้างไฟล์ .xlsx เองใน `src/lib/xlsx.ts`) จึงรันได้ทั้งบนเครื่อง, **bolt.new / StackBlitz** และ **Vercel**

## รันบน bolt.new / StackBlitz

1. สร้างโปรเจกต์ใหม่ แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวาง (ถ้าใช้โปรเจกต์เดิม ให้ลบไฟล์เก่าทิ้งก่อน โดยเฉพาะ `next.config.ts`, `postcss.config.mjs`, `tsconfig.app.json`, `tsconfig.node.json`, โฟลเดอร์ `src/app`)
2. ใน Terminal พิมพ์ `npm install` แล้ว `npm run dev`
3. หน้าตัวอย่างจะเปิดที่พอร์ต 3000

## Deploy บน Vercel

1. push โฟลเดอร์นี้ขึ้น GitHub (ใน bolt.new กด **Create a repository** ได้เลย)
2. ที่ vercel.com เลือก **Add New → Project** แล้วเลือก repository นั้น
3. Vercel ตรวจพบ Vite เอง (Build: `npm run build`, Output: `dist`) กด **Deploy**

ไม่ต้องตั้ง environment variable และไม่ต้องมีฐานข้อมูล

## ข้อสมมติที่ควรทราบ

- **EF ไฟฟ้า:** ค่าเริ่มต้นคือ 0.4750 kgCO₂e/kWh (อบก. CFO มีผล 1 ม.ค. 2569) ส่วนค่า 0.4999 ตามคู่มือ/Worksheet เลือกได้ในหน้าตั้งค่า สำหรับโครงการ T-VER ให้ใส่ Grid EF ที่ อบก. ประกาศล่าสุดเอง
- **ใบไม้ตามสมการ Ogawa:** WL = (28/(WS+WB) + 0.025)⁻¹ แทนค่าเป็นตัน ให้ 62.99 กก. สำหรับต้นตะแบกตัวอย่าง (สไลด์ อบก. แสดง 63.09 กก.; รวมทั้งต้นต่างกัน 0.2 kgCO₂)
- **ปริมาณเศษวัสดุอ้างอิง:** อ้อยและข้าวโพดคำนวณย้อนจาก IPCC Table 2.4 ควรแทนด้วยค่าวัดจริงในพื้นที่
- **ผลในโหมด T-VER เป็นการประมาณการเบื้องต้น** ยังไม่รวมบัฟเฟอร์ความถาวรของโครงการป่าไม้ วิธีตรวจวัดจริง/แบบจำลอง (Method 1–2 ของ 13-08, P-TOOL-01-13) และ U_d ของ P-METH-13-06 ตั้งต้น 15% ตามหลักอนุรักษ์ (ปรับได้)
- **ข้อมูลอยู่ในเบราว์เซอร์ของแต่ละเครื่อง** หากต้องการรวมข้อมูลหลายเจ้าหน้าที่แบบอัตโนมัติ เฟสถัดไปควรเพิ่มฐานข้อมูลกลาง เช่น Supabase พร้อมระบบผู้ใช้
